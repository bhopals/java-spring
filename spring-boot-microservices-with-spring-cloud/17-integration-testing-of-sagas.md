### Spring Cloud Contract

- Spring Cloud Contract is an umbrella project holding solutions that help users in successfully
  implementing the Consumer Driven Contracts approach. Currently Spring Cloud Contract consists of the Spring Cloud Contract Verifier project.

- Spring Cloud Contract Verifier features:

  - Ensure that HTTP / Messaging stubs (used when developing the client) are doing exactly what
    actual server-side implementation will do
  - Promote acceptance test driven development method and Microservices architectural style
  - To provide a way to publish changes in contracts that are immediately visible on both sides
    of the communication
  - To generate boilerplate test code used on the server side

- More - https://spring.io/projects/spring-cloud-contract/
